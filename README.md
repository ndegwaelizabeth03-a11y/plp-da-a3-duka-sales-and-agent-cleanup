# Duka Sales and Agent Clean-Up
**Duka:** H1 2026 sales exploration (Excel check included). **Agents:** audit, clean, merge, summarise.

Run: `pip install -r requirements.txt`, `python generate_data.py`, then run `duka_sales_exploration.ipynb` and `agent_cleanup.ipynb`.

Agent rows: 612 before, 600 after cleaning.

## Executive Summary
- Revenue was KES 71.8M from 1,000 orders in Jan-Jun 2026.
- Nairobi led with KES 26.1M (36%) from 376 orders.
- Laptops earned KES 41.5M (58%) while Tablets sold most units (691).
- Weekends had 277 orders averaging KES 71,972 vs 71,724 on weekdays.
- April peaked at KES 13.5M, 24% above June's KES 10.9M.
